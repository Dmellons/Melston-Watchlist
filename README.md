# Melston Watchlist

A full-stack media tracking app for movies, TV shows, video games, and physical
media. Track what you want to watch, rate what you've finished, get AI-powered
recommendations, look up streaming availability, scan barcodes to catalog your
physical collection, and (for permitted users) request titles be added to a Plex
server.

Built with **Next.js (App Router) + React 19 + TypeScript**, backed by a
self-hosted **Appwrite** instance, and styled with **Tailwind CSS** and **Radix
UI**.

---

## Features

### Watchlist & tracking
- Personal watchlist of movies and TV shows with poster/backdrop art.
- Watch status per item: `want_to_watch`, `watching`, `completed`, `on_hold`,
  `dropped`.
- 1–10 ratings, user reviews, favorites, tags, rewatch counts, and
  per-show season/episode progress.
- Search (TMDB multi-search) with genre filtering.
- Export your watchlist to Excel.

### Discovery
- Home page with trending, now-playing, and popular rows from TMDB.
- "New & Upcoming" page (now playing, upcoming, on the air, airing today).
- Rich movie/TV detail pages: cast, images, videos, certifications,
  streaming providers, recommendations, and similar titles.

### AI recommendations
- Personalized suggestions generated by a self-hosted, OpenAI-compatible LLM
  server (vLLM). Suggestions are built from your watchlist preferences (genres,
  ratings, history) and enriched with TMDB metadata.
- Free-text prompt plus a media-type filter (movie / tv / game / all).

### Games
- Game search and detail pages powered by **IGDB** (cover art, screenshots,
  platforms, genres, release dates).
- Xbox Game Pass availability check.
- Steam library import: resolve a Steam ID / vanity URL / profile URL and pull in
  owned games.

### Physical media library
- Catalog DVDs, Blu-rays, and physical games.
- **Barcode scanner** (camera-based, via `html5-qrcode`) with UPC/EAN lookup.
- Manual add form and TMDB metadata matching.

### Collections
- Create custom named collections and organize watchlist items into them.

### Plex integration
- Users with the `plex` label can toggle a "request" on any title.
- A Python sync script keeps an Appwrite collection in step with the Plex
  library so the app knows what's already available.

### Admin
- Admin dashboard with platform stats and Plex request queue.
- User management (roles, status, item/request counts, activity).
- Analytics: rating distribution, watch-status breakdown, top-rated titles,
  most active users, month-over-month growth.

## Getting started

### Prerequisites
- Node.js `>= 20.9.0` and npm `>= 10.0.0`
- A running Appwrite instance (project + collections — see schema in
  `lib/server/appwrite-schema.json`)
- API credentials for the external services you want to enable (TMDB, IGDB,
  Steam, etc.)

### Install & run

```bash
npm install
npm run dev        # start the dev server
# npm run host     # dev server bound to all interfaces (LAN access)
```

The app runs at `http://localhost:3000`.

## Environment variables

Create a `.env` (or `.env.local`) in the project root. Variables prefixed with
`NEXT_PUBLIC_` are exposed to the browser; the rest are server-only secrets.

```bash
# App
NEXT_PUBLIC_URL_BASE=            # public base URL of the app
NEXT_PUBLIC_USER_DEBUG=false
COOKIE_NAME=                     # name of the JWT session cookie

# Appwrite
NEXT_PUBLIC_APPWRITE_ENDPOINT_URL=
NEXT_PUBLIC_APPWRITE_PROJECT_ID=
NEXT_PUBLIC_APPWRITE_WATCHLIST_COLLECTION_ID=
NEXT_PUBLIC_APPWRITE_PLEX_COLLECTION_ID=
NEXT_PUBLIC_APPWRITE_PHYSICAL_MEDIA_COLLECTION_ID=
NEXT_PUBLIC_APPWRITE_COLLECTIONS_COLLECTION_ID=
NEXT_PUBLIC_APPWRITE_RATINGS_COLLECTION_ID=
APPWRITE_API_KEY=                # server-only admin key

# TMDB
NEXT_PUBLIC_TMDB_API_READ_ACCESS_TOKEN=
NEXT_PUBLIC_TMDB_API_KEY=

# Games
IGDB_CLIENT_ID=
IGDB_CLIENT_SECRET=
STEAM_API_KEY=                   # server-only

# AI
AI_SERVER_URL=                   # OpenAI-compatible vLLM endpoint

# Plex
PLEX_TOKEN=                      # server-only
PLEX_SERVER_BASE_URL=
```

> Keep `.env` out of version control (it already is via `.gitignore`). Never
> commit real keys.

## Data model (Appwrite)

| Collection | Purpose |
| ---------- | ------- |
| `watchlist` | User watchlist items (status, rating, review, progress, art, tags, `plex_request`). Document-level permissions per user. |
| `physical_media` | Physical inventory (title, format, barcode, condition, notes). |
| `collections` | User-created collections (name, owner, item IDs). |
| `ratings` | Ratings data used for analytics. |
| Plex collection | Mirror of titles available on the Plex server (kept in sync by the Python script). |

User-level settings (streaming providers, notifications, Steam ID, profile
image) are stored in Appwrite account preferences. Roles are managed via Appwrite
labels: `admin` (admin dashboard), `plex` (can request titles), `tester` (beta
features).

The full schema is checked in at `lib/server/appwrite-schema.json`.

## Authentication

Authentication uses Appwrite accounts (email/password or Google OAuth):

1. On login, the client obtains a JWT via the Appwrite Account API.
2. The JWT is posted to `/api/jwt/set` and stored in an HttpOnly, secure cookie.
3. Server components read the cookie to create an authenticated Appwrite client
   (`createSessionClient`); privileged server actions use the API key
   (`createAdminClient`).
4. `/api/jwt/delete` clears the cookie on logout.

## Plex sync (optional)

`backend/plex/main.py` scans the Plex library and upserts available titles into
the Appwrite Plex collection so the app can show what's already on the server.

```bash
cd backend/plex
pip install -r requirements.txt
python main.py
```

It reads the same `.env` from the project root (`PLEX_TOKEN`,
`PLEX_SERVER_BASE_URL`, and the Appwrite settings). Run it on a schedule (e.g.
cron) to keep availability current.
